==================================================
ИНСТРУКЦИЯ ПО РАБОТЕ С API (localhost:8080)
==================================================
Дата: 10 ноября 2025 г.
Инструмент: cURL (Консоль)
Базовый URL: http://localhost:8080/api

ВСЕ защищенные запросы должны содержать заголовок авторизации. Замените YOUR_TOKEN_HERE на ваш актуальный Bearer-токен.

ЗАГОЛОВОК АВТОРИЗАЦИИ:
-H "Authorization: Bearer YOUR_TOKEN_HERE"

==================================================
РАЗДЕЛ I: ПОСТЫ (/api/posts)
==================================================

1. ПОЛУЧЕНИЕ ДАННЫХ (READ)

   1.1. Получить СПИСОК ВСЕХ ПОСТОВ
   Метод: GET
   URL: /api/posts
   Команда:
   curl -X GET http://localhost:8080/api/posts \
   -H "Authorization: Bearer YOUR_TOKEN_HERE"

   1.2. Получить ОДИН ПОСТ по ID (например, ID 3)
   Метод: GET
   URL: /api/posts/{id}
   Команда:
   curl -X GET http://localhost:8080/api/posts/3 \
   -H "Authorization: Bearer YOUR_TOKEN_HERE"

--------------------------------------------------

2. СОЗДАНИЕ ПОСТА (CREATE)

   Метод: POST
   URL: /api/posts
   Требуется заголовок: -H "Content-Type: application/json"
   Команда:
   curl -X POST http://localhost:8080/api/posts \
   -H "Authorization: Bearer YOUR_TOKEN_HERE" \
   -H "Content-Type: application/json" \
   -d '{
       "primaryImageUrl": "https://example.com/front.jpg",
       "secondaryImageUrl": "https://example.com/back.jpg",
       "caption": "Мой новый пост.",
       "visibility": "FRIENDS_ONLY" 
   }'

--------------------------------------------------

3. ОБНОВЛЕНИЕ ПОСТА (UPDATE)

   3.1. Полное обновление (PUT) поста по ID (например, ID 3)
   Метод: PUT
   URL: /api/posts/{id}
   Команда:
   curl -X PUT http://localhost:8080/api/posts/3 \
   -H "Authorization: Bearer YOUR_TOKEN_HERE" \
   -H "Content-Type: application/json" \
   -d '{
       "id": 3,
       "userId": 2,
       "primaryImageUrl": "https://example.com/updated_front.jpg",
       "secondaryImageUrl": "https://example.com/updated_back.jpg",
       "caption": "Обновленный текст поста.",
       "visibility": "PUBLIC"
   }'

--------------------------------------------------

4. УДАЛЕНИЕ ПОСТА (DELETE)

   Метод: DELETE
   URL: /api/posts/{id}
   Команда:
   curl -X DELETE http://localhost:8080/api/posts/3 \
   -H "Authorization: Bearer YOUR_TOKEN_HERE"

==================================================
РАЗДЕЛ II: АУТЕНТИФИКАЦИЯ И ПОЛЬЗОВАТЕЛИ
==================================================

1. РЕГИСТРАЦИЯ (Создание пользователя)

   Метод: POST
   URL: /api/auth/register (предполагаемый путь)
   ВНИМАНИЕ: Обычно не требует токена.
   Команда:
   curl -X POST http://localhost:8080/api/auth/register \
   -H "Content-Type: application/json" \
   -d '{"username": "new_user", "email": "user@mail.com", "password": "secure_password"}'

--------------------------------------------------

2. ВХОД (Получение токена)

   Метод: POST
   URL: /api/auth/login (предполагаемый путь)
   ВНИМАНИЕ: Не требует токена. Результатом будет новый токен.
   Команда:
   curl -X POST http://localhost:8080/api/auth/login \
   -H "Content-Type: application/json" \
   -d '{"username": "duwniy", "password": "вашій_пароль"}'

--------------------------------------------------

3. ПОЛУЧЕНИЕ ИНФОРМАЦИИ О СЕБЕ

   Метод: GET
   URL: /api/users/me (предполагаемый путь)
   Команда:
   curl -X GET http://localhost:8080/api/users/me \
   -H "Authorization: Bearer YOUR_TOKEN_HERE"
